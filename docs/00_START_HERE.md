## 💡 DECISION POINTS (Already Made)

### Architecture
✅ **Dual Dataset (2A + 2B)** not Single Dataset
- Why: Better security, separate refresh cycles, easier maintenance

✅ **Import Mode** not DirectQuery
- Why: Faster queries, offline capability, refresh daily (acceptable)

✅ **Service Principal for Refresh** not User-triggered
- Why: Automated, no user intervention, reliable 04:00 UTC trigger

✅ **7-Day SAS URLs** not Permanent Links
- Why: Security, auto-cleanup, prevents stale links

✅ **Versioned Reports** (v1, v2) not Overwrites
- Why: Audit trail, rollback capability, version history
